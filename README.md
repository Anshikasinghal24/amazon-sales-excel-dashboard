# 📊 Amazon Product Performance Dashboard – Excel

## 📌 Project Overview

This project presents an interactive Amazon Product Performance Dashboard
developed using Microsoft Excel.

The dashboard analyzes product performance, pricing, discounts, ratings,
customer engagement and product distribution across different categories.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Dashboard
- Data Analysis

## 📊 Dashboard Analysis

The project includes:

- Product Analysis
- Rating Analysis
- Discount Analysis
- Price Analysis
- Customer Engagement Analysis
- Top 10 Products
- Product Distribution by Category

## 📈 Key KPIs

- Total Products: 1,465
- Average Rating: 4.10
- Average Discount: 47.69%
- Total Reviews: 26,766,377

## 🔍 Key Insights

- Electronics has the highest number of products.
- Electronics receives the highest customer engagement.
- Office Products have the highest average rating.
- Home Improvement has the highest average discount.
- Discounted prices are significantly lower than actual prices.
